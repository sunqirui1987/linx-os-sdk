# 音频服务测试Demo

本目录包含了音频服务（AudioService）的完整测试demo，用于验证音频服务的所有核心功能。

## 文件说明

### 测试文件

1. **simple_audio_test.c** - 简化测试demo
   - 专注于核心功能验证
   - 不依赖复杂的外部组件
   - 适合快速验证基本功能

2. **audio_service_test.c** - 完整功能测试demo
   - 测试所有音频服务功能
   - 包含模拟的音频数据生成
   - 验证回调机制和队列操作
   - 提供详细的统计信息

3. **CMakeLists.txt** - 构建配置文件
   - 支持编译测试程序
   - 自动链接必要的库

## 编译和运行

### 前提条件
- CMake 3.10 或更高版本
- GCC 或 Clang 编译器
- pthread 库
- 数学库 (libm)

### 编译步骤

1. 创建构建目录：
```bash
mkdir build
cd build
```

2. 配置CMake：
```bash
cmake ..
```

3. 编译：
```bash
make
```

### 运行测试

1. 运行简化测试：
```bash
./bin/simple_audio_test
```

2. 运行完整测试：
```bash
./bin/audio_service_test
```

## 故障排除

### 常见问题

1. **编译错误**
   - 检查是否安装了所有依赖库
   - 确认CMake版本是否满足要求
   - 检查头文件路径是否正确

2. **运行时错误**
   - 确认所有依赖的动态库都可用
   - 检查权限设置
   - 查看详细的错误日志

3. **测试失败**
   - 检查系统资源是否充足
   - 确认音频设备是否可用
   - 查看具体的失败原因

### 调试建议

1. 使用Debug模式编译：
```bash
cmake -DCMAKE_BUILD_TYPE=Debug ..
```

2. 使用GDB调试：
```bash
gdb ./bin/simple_audio_test
```

3. 启用详细日志：
```bash
export LINX_LOG_LEVEL=DEBUG
./bin/audio_service_test
```

## 扩展测试

### 添加新的测试用例
1. 在相应的测试文件中添加新的测试函数
2. 在main函数中调用新的测试函数
3. 更新CMakeLists.txt（如果需要新的依赖）

### 集成到CI/CD
测试程序返回值：
- 0: 所有测试通过
- 非0: 有测试失败，返回值为失败测试的数量

可以在CI/CD脚本中使用：
```bash
./bin/simple_audio_test
if [ $? -eq 0 ]; then
    echo "所有测试通过"
else
    echo "测试失败"
    exit 1
fi
```

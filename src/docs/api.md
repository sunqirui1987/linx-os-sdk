# 用户 API 协议规范

## 声音 

| 系统  | 功能          | 描述               | 备注             | 优先级   |
|-------|---------------|--------------------|------------------|-------------|
| 声音  | `say M, SayOptions{Voice string, LipSync bool}`       | 用角色Voice（没有Voice就是预先配置机器人自己的声音）的声音，说 M（Message） 【这个M可以是文本，也可以是SSML标记语言】   | 用角色声音来说话，LipSync是否同步口型 | 高 |
|       | `play S, PlayOptions{LipSync bool}`      | 播放 S（Sound）    | 播放一段声音，lipsync是否同步口型      | 高 |
|       | `setVolume`   | 设置音量为 V       |                  | 中 |
|       | `volume`      | 当前音量          |                  | 中 |


## UI显示

| 系统  | 功能          | 描述               | 备注             | 优先级 |
|-------|---------------|--------------------|------------------|------|
| UI显示  | `setFace M`  | 设置人脸为 M（Model） | 设置人脸模型。这个3d模型可以由一张照片通过AI生成，也可以由一个3d模型文件导入。参考：https://www.meshy.ai/ | 高 |
|        | `playExpression name, options?`  | 播放表情动画，name为表情名称，options为可选参数 | 预设表情示例：<br>• happy: 开心表情<br>• sad: 伤心表情<br>• surprised: 惊讶表情<br>• angry: 生气表情<br>• neutral: 中性表情<br>• confused: 困惑表情<br>• fear: 恐惧表情<br>• disgust: 厌恶表情<br><br>options参数示例：<br>```{speed: 1.2, repeat: 2, intensity: 0.8}```| 高 |






## 地图/移动 

| 系统      | 功能            | 描述                                                                                                     | 备注                     |
|-----------|-----------------|--------------------------------------------------------------------------------------------------------|--------------------------|
|           | `goto O[, D]`    | 走到 O 前 D 毫米处<br>• 空间中的命名物体<br>• 某个命名的人或动物，根据声纹和外观特征辨识<br>• 某个命名的房间<br>• 之前记录的某个 position | e.g., `goto LivingRoom` |
|           | `turn A`        | 旋转A角度         |                          |
|           | `position`      | 取当前位置                                  |                          |
|           | `pos, ok := find(O)`        | 根据图片/对象名寻找物体<br>e.g. `pos, ok := find("shoes")`        | 新增              |
|           | `cmdVel x,y,angle`        |  运动速度控制   	x：沿前后方向的速度。y：沿左右方向的速度（如侧向漂移）。z：旋转速度，表示机器人转向的快慢， 机器人逆时针旋转（正方向），机器人顺时针旋转（负方向）。        |                      新增    |

## 设备管理

|-----------|---------------------------|--------------------|--------| ------|
| 设备管理  | `mount D[, P]`             | 在端口 P 安装设备 D  |        | 低 |
|           | `umount D`                | 卸载设备 D         |        | 低 |
|           | `device(D)`               | 安装设备 D 对象     | 修改   | 低 |

## 通信 

| 系统  | 功能          | 描述                                                                                      | 备注 | 优先级 |
|-------|---------------|-------------------------------------------------------------------------------------------|------| ------|
| 通信  | `chat M[, G]`  | 向 G 发送消息 M<br>G 可以是：某个提前生成的群、绑定社交网络的人或 Robot<br>未指定 G 则默认使用 Chat Group |    | 低 |
|       | `alert M`     | 发送告警 M<br>警告行为：优先社交网络发送→无回复发送短信&邮件→无回复电话（可选）             |    | 低 |
|       | `sms M[, P]`   | 向 P 发送短信 M<br>未指定 P 则向主人发送                                                       |    | 低 |
|       | `mail M[, P]`  | 向 P 发送邮件 M<br>未指定 P 则向主人发送                                                       |     | 低 |
|       | `broadcast M[, param]` | 广播消息 M |    | 低 |

## 事件 
| 系统  | 功能                 | 描述                                                                                                      | 优先级 |  |
|-------|----------------------|-----------------------------------------------------------------------------------------------------------|------| ------|
| 事件  | `onScene => { … }`   | 切换场景时发生：Robot 从 A 搬到 B，A 和 B 不在同一地图。             | 低 |
|       | `onCall P, o => { … }`  | 听到 P 叫我，P 是某人或动物，o 包含 P 是谁、说了什么。                         | 高  |
|       | `onCall o => { … }`     | 听到有人叫我，动态判断 o 是谁和内容，再决定行为。           | 高  |
|       | `onCall P, => { … }`    | 听到 P 叫我，不关心内容。                                      | 高  |
|       | `onCall => { … }`       | 听到有人叫我，不关心是谁或内容。                              | 高  |
|       | `onAlert o => { … }`    | 告警触发，o 为告警对象，类型如：烟雾/火灾、偷盗、摔倒等。                 | 低 |
|       | `onPower C, => { … }`   | 电量满足条件 C 时触发：如`< X%`、`> X%`、`100%`。                      | 低 |
|       | `onTime T, => { … }`    | 到时间点 T 触发：如`mm:ss`每小时、`hh:mm:ss`每天等。                    | 低 |
|       | `OnDevice T => { ... }` | 监听指定类型设备(usb/serial/camera/lidar/audio)的挂载、卸载和错误状态。空就是所有设备 | 低 |
|       | `onMsg M, => { … }`    | 收到消息 M。                          | 低 |
|       | `onMsg M, param => { … }`    | 收到消息 M，参数为 `broadcast` 带的 param 参数，可以为 nil。    | 低 |
|       | `onTouchStart S, => { … }`    | 碰到精灵 S（实际 onTouchStart 由 MainApp 检测，在检测到碰撞后反向通知机器人）。     | 低 |
|       | `onTouchStart S, o => { … }`    | 碰到精灵 S，参数 o 是碰到的精灵实例。     | 低 |
|       | `onTouchStart [S1, S2, ...], o => { … }`    | 碰到精灵 S1, S2 ... 中的一个，参数 o 是碰到的精灵实例。     | 低 |
|       | `onRobotStart R, o => { … }`    | 当 R 类型的机器人启动时触发，参数 o 是启动的机器人实例。机器人只产生该事件但不响应它。 | 低 |
|       | `onRobotState R, o => { … }`    | 当 R 类型的机器人状态改变时触发，参数 o 是机器人的状态实例。机器人只产生该事件但不响应它。 | 低 |
|       | `onAct P, A, => { … }` | 当 P 这个人发生 A 动作时 | 高 |
|       | `onAct A, o => { … }` | 当有人发生 A 动作时。o 里面记录了做 A 动作的人是谁。 | 高  |
|       | `onObjectStart X, e => { … }` | 当检测到有物体 X 时（X 可以是某种物体类别，也可以是某个命名物体）。其中 e.Objects 记录了检测到的相关问题信息。 | 高 |
|       | `onObjectStart [X1, X2, ...], e => { … }` | 当检测到有物体 X1, X2 ... 中的某一个或多个时。其中 e.Objects 记录了检测到的相关问题信息。 | 高  |
